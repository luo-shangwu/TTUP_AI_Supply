# AI 会员微信核心话术

> 从 [Language.md](./Language.md) 提炼的高频版本。
>
> 将 `【】` 中的内容替换为实际订单信息。微信沟通时逐条发送，客户完成当前步骤后再发送下一条。

## 快速流程

> 了解用途 → 判断用量 → 核验账号 → 推荐套餐 → 确认价格与保障 → 选择充值方式 → 到账验收 → 售后回访

## 1. 首次接待

```text
你好，可以充值的～

为了不让你多花钱，我先了解一下实际需求：
1. 想充值 ChatGPT、Claude 还是 Grok？不确定也可以由我帮你选。
2. 主要想用 AI 做什么？比如学习、论文、代码、写作还是工作？
3. 大概是偶尔使用，还是每天高频使用？
4. 是充值自己的账号，还是需要新成品号？当前订阅到期了吗？

你简单回复我就行，我会按需求和账号状态给你推荐，不会让你盲目买高档套餐。
```

### 第一次使用 AI

```text
第一次用也没关系，我会从套餐选择、账号检查到充值完成一步一步带你操作。

如果还没有安装客户端或账号，也可以提供安装、注册和基础使用指导，费用会提前单独说明。
```

```text

这个档位已经能够覆盖你的主要需求，暂时没有必要多花钱上更高档。

走正规订阅渠道，充值完成后可以直接在对应平台账号内核对套餐名称和到期时间。
本单提供【30 天订阅保障 / 订阅期保障】，具体保障范围下单前都会提前说明。
```

### ChatGPT 档位速选

```text
如果只是日常问答、写作和学习，Plus 一般就够用。

如果经常遇到基础额度不够，需要高频写作、代码或资料处理，可以考虑 Pro 5X。

只有明确有大量资料处理和长时间连续任务时，才建议 Pro 20X，不需要盲目追求最高档。
```

```text
我们不是只发一张卡密就结束：

售前会免费核验账号状态并帮助选型；
售中会明确充值渠道、操作步骤和当前进度；
```

## 4. 选择充值方式

```text
充值有两种方式，你选择自己方便的就可以：

① 客服协助充值
你登录自己的 ChatGPT，打开官方 Session 页面，把完整 JSON 发给我，我来帮你提交充值。
不需要单独提供账号密码、验证码或恢复码，操作比较省事。

② 卡密自助充值
我把卡密和自助充值网址发给你，你自己登录 ChatGPT、获取 Session，然后在页面提交。
整个操作都由你自己完成，账号信息不用发给我。

想省事选①；比较重视隐私或者熟悉操作，可以选②。
```

> **内部提醒：** Session JSON 属于敏感登录凭证，不能描述成“无意义的乱码”。客户介意发送时，直接推荐卡密自助充值；任何方式都不要索取验证码、恢复码或支付密码。

## 5. 客服协助充值

### 第一步：登录账号

```text
好的，我们现在开始操作，我一步一步带你来。

请先在浏览器登录需要充值的 ChatGPT 账号，注意确认登录的是正确账号。
```

### 第二步：获取 Session JSON

```text
登录成功后，打开这个 ChatGPT 官方链接：
https://chatgpt.com/api/auth/session

打开后会看到一整段 JSON 内容，看起来像很长的代码，这是正常的。
请完整复制，不要遗漏开头或结尾，然后发给我。

Session 属于敏感的临时登录凭证，只用于本次充值，请不要发送给其他人。
如果介意发送 Session，也可以随时改选卡密自助方式。
```

### 第三步：核对并提交

```text
收到，我先核对一下账号信息。

系统识别到的邮箱是：【脱敏邮箱】
麻烦确认一下，这是需要充值的账号吗？
```

客户确认后：

```text
好的，账号核对无误，现在为你提交充值。
一般几分钟内完成，期间先不要切换账号，我完成后马上通知你。
```

## 7. 高频问题

### Session 页面打不开

```text
先确认浏览器里已经登录 ChatGPT，并且能够正常打开 chatgpt.com。
登录成功后，再用同一个浏览器打开 Session 链接。
```

### 页面出现一长串内容

```text
对的，就是这段很长的 JSON 内容，不是报错。
需要完整复制，开头和结尾都不要遗漏。
```

### 客户担心安全

```text
可以理解。Session 本身属于敏感的临时登录凭证，所以介意发送的话，建议选择卡密自助充值，全程由你自己操作。

无论选择哪种方式，我们都不会索要验证码、恢复码或支付密码。
```

### 客户觉得价格高或说别处更便宜

```text
低价渠道确实有，但建议同时比较充值来源、账号要求、到账核验方式和售后范围，不能只看最终数字。

我们的服务价包含下单前账号核验、渠道选择、操作指导和约定范围内的订阅售后。我会按你的实际需求推荐，不会为了卖高价套餐让你盲目升级。
```

### 客户担心操作复杂

```text
不用担心，你不需要提前会操作。

选择客服协助的话，我会一步一步发给你，每完成一步再进行下一步；如果希望自己掌握账号信息，也可以选择卡密自助，我同样会全程指导。
```

### 客户说“我再想想”

```text
没问题，购买前考虑清楚更好。

我先把适合你的方案和注意事项发给你。之后决定购买时，把当前订阅页面发我再核验一次，避免账号状态变化后选错渠道。
```

### 提交后暂未显示会员

```text
充值结果可能需要一点时间同步。
请先刷新 ChatGPT，或者退出账号后重新登录，再查看订阅状态。
如果仍未显示，把页面截图发给我，我继续帮你核查。
```

## 9. 售后处理

```text
收到，我来帮你核查。为了尽快定位问题，请发我以下信息：

1. 购买的套餐名称和大致下单时间；
2. 账号邮箱的脱敏信息，例如 a***@gmail.com；
3. 当前订阅页面和报错页面截图；
4. 问题首次出现的时间，以及出现前做过什么操作。

先不要重复充值，也不要发送密码、验证码或恢复码。我核对后告诉你下一步怎么处理。
```

### 售后边界

```text
本单保障的是约定范围内的订阅异常。

账号封禁、异常登录环境、频繁切换地区、多人共享、逾期账单、违规使用、KYC 或手机号验证等账号风控问题，不属于订阅保障范围。

如果遇到账号风控，我们可以协助核查订单并提供申诉指引，但审核和恢复结果由对应平台决定。
```
